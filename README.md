# Minfaro · Opportunity AI

An opportunity discovery and decision-support application for scholarships, internships, jobs, fellowships, grants, and competitions.

**Documentation-only portfolio showcase by Farook Fahath.**

## Features

- Opportunity browsing, detail pages, source information, and saved listings.
- Structured profiles covering education, skills, languages, and work experience.
- Deterministic requirement checks with PASS / FAIL / UNKNOWN results and eligibility explanations.
- Application tracking, reminder preferences, notifications, and discovery/expiry workers.

## Technology

React, TypeScript, Vite, React Router; Python, FastAPI, SQLAlchemy, PostgreSQL, Alembic; ESCO skill data.

## Current status

Application in development with implemented frontend and backend workflows. Public availability is unverified. A local recording plan exists, but it explicitly says no recording was made; it is not a published demo video.

## Scope and limitations

Match scores express known requirement fit, not selection probability. Unknown requirements require review; users should check official opportunity sources. Roadmap items are not presented here as completed features.
